# Food Delivery System (DBMS Mini Project)

Stack: MySQL + Python Flask (backend) + HTML/CSS/JavaScript (frontend)

## Run steps
1. Install Python 3.9+ and MySQL Server + Workbench.
2. In Workbench open `food_delivery_system.sql` and run it (Ctrl+Shift+Enter).
3. Open `app.py` and set your MySQL password in DB_CONFIG (or set DB_PASSWORD env var).
4. In a terminal inside this folder:
       python -m venv venv
       venv\Scripts\activate          (Windows)   |   source venv/bin/activate   (Mac/Linux)
       pip install -r requirements.txt
       python app.py
5. Open http://127.0.0.1:5000 in your browser.
